encoding

encoding is a agreed meanings of characters. Is a agreed-upon mapping between numbers and meanings

ASCII

ASCII was one of the earliest standard for english letters. American Standard Code for Information Interchange.
Use 7 digits. ASCII acts as a bilingual dictionary between text and numeric codes.
Cover english letters, digits and basic punctiation.

The ISO/IEC 8859 Series created several standards; each standard covered a set of languages:
- ISO-8859-1: Covered Spanish, Italian,Portuguese, Catalan, and Nordic languages

Unicode

Unicode is a universal character encoding standard. It assigns unique code points to characters. Unicode supports the interchange, processing, and display of text in diverse languages.
It is clear how opening a document requires us to use the same encoding used when saving it; otherwise, various characters will not be displayed corectly or they might be 
incorrectly replaced.

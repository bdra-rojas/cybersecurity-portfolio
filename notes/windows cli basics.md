What is the windows command Line?

The command Prompt is a text-based interface for interacting with the windows operating system. Instead of clicking windows and folders, you type
commands that tell the computer exactly what to do.

cd ==> show the full path of the directory you're currently in. Also used to change directory.
dir ==> This command will list down the files and folders presente in the current directory.
dir /a ==> Show the everything, including hidden items
dir /s <name> ==> this command help to locate the file and provided full path.
type <name> ==> read the content of the file.
whoami ==> This command prints the username of the account you're currently loggend into.

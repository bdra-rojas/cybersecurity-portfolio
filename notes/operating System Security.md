Authentication and Weak Passwords

Authentication is the act of cerifying your identity, this can be achieved via three main ways:
- Something you know, such a password or a PIN Code
- Something you are, such a fingerprint
- Something you have, such a phone number via you can recieve an SMS message+

The password is the methods most common form of authentication, they are also the most attacked. 

Weak File Permissions

Proper security dictates the principle of least privilege, who say any file is accecible only by those who need to access it to get work.
This principle in simple terms is "who can access wath".
Weak file permissions make it easy for the adversary to attack confidentiality and integrity.

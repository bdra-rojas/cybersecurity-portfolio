Operating system(OS)
 An operating system is the core software that coordinates everything happening on a computer.

System Privilege Layers

Inside a modern computer, different parts of the system operate at various permission levels. This separation is intentional and helps prevent conflict and security issues

- Kernel Space: The privileged, locked-down core of the OS. This is the part of the operationg system that directly manages hardware and system resources, runs.
- User Space:  Wher all standard applications run. Whenever they need to open or save a file, play a sound, or connect to Wi-Fi, they must make a system call an request that the kernel act on their behalf.

Operating Systems Duties

- Process Management ==> Creates, schedules, prioritizes, and terminates programs. The OS Decides how much CPU time each process gets.
- Memory Management ==> Allocates RAM to processes, protectes the app's memory from other processes, and reclaims memory when apps are closed. When the RAM is lows, the OS uses virtual memory to keep your system stable.
- File System Management ==> Organize files into directories, handles naming, paths, permissions, metadata.
- User management ==> Handles multiple user accounts, authentication, and permissions to determinate who can access what.
- Device Mangement ==> Loads direvers and provides a universal interface.

At basics level, the OS handles:
- Authetication ==> verifies who you are through login passwords and biometrics
- Permissions ==> Controls exactly what each user and app is allowed to read, write, or execute
- Isolation ==> Keeps every process in its own protected box 
- System Proteccion ==> Safeguards critical system files and settings from unauthorized changes

OS Interfaces

Interaction with he OS can be divided into two main parts: 
- the graphical user interface(GUI)
- command-line interface(CLI)
